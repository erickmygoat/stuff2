# My Son: Sovereign AGI Startup Guide

Welcome to the "My Son" Autonomous Agent.

## Prerequisites

1.  **Python 3.10+**: [Download](https://www.python.org/downloads/). Check **"Add Python to PATH"**.
2.  **Ollama**: [Download](https://ollama.com). Run `ollama run llama3` in a terminal.

## Installation & Setup

1.  **Build the Launcher**:
    *   Double-click **`make_launcher.bat`**.
    *   This will install dependencies and create **`Launcher.exe`**.
    *   Wait for the "SUCCESS" message.

2.  **Run the Agent**:
    *   Double-click **`Launcher.exe`**.
    *   The dashboard will open automatically.

## Troubleshooting

*   **"Python not found"**: Reinstall Python and ensure "Add to PATH" is checked.
*   **"Brain Offline"**: Make sure Ollama is running.
