# My Son AGI - Setup Guide

## 1. Prerequisites
*   **Python 3.10+** (with "Add to PATH").
*   **Ollama** (running `llama3`).

## 2. Creating the Launcher
1.  Run **`make_launcher.bat`**.
2.  This creates **`Launcher.exe`**.

## 3. Running
1.  Run **`Launcher.exe`**.
2.  The GUI will open. Global access URL is shown in the logs if you need mobile control.
